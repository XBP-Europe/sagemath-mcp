# Search

Searching for multiple words only shows matches that contain
all words.

Note also that you can also call "search\_src(...)"
in Sage to search Sage's source code.

> **Not available through this server.** `search_src` and `search_doc` read the
> SageMath installation from inside the worker, so they are not among the names
> caller code may use. Search the manual at
> <https://doc.sagemath.org/html/en/reference/> instead — these pages are a
> local copy of its index.
