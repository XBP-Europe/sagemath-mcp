# Minimum versions for packages that the sagemath/sagemath base image ships in
# Sage's own Python environment, raised when a security fix lands before a new
# base image carries it. The release Dockerfile and `make sage-deps` (which the
# integration suite runs on) both install this file, so CI tests exactly what
# the image ships. pip only acts when the installed version is below a floor.
# The passagemath runtime takes these packages from uv.lock instead, and
# tests/test_sage_security_floors.py fails if the lock falls below a floor.
#
# Remove a line once the base image ships a version at or above it.

# whose intermediate CA keys were compromised. Base image 10.10: 2026.02.25.
